## 0.2.0 (the -LAB standard; local only, clean history from the old repo's main)

- Brought to the -LAB standard without adding a feature. Title and repo name end in LAB; README in the twelve-section README standard with `Tier: Tester`, `Repo:` and `Catalog: D54`; short CLAUDE.md; Node 26 only (`engines`, `.nvmrc`, Dockerfile, CI); GitHub-hosted `ci.yml` copied from a sibling (build, test, doctor, forbidden-strings, gitleaks); scripts `start`, `dev`, `test`, `build`, `doctor`, `reset`, `prepare`, `smoke`.
- Mock/Live toggle in the header on every page, with the mode shown and the banner saying the same mode. Live is refused (`GET /api/info` names the failing guards): there is no live gateway. The default mode comes from `GATEWAY_INSPECTOR_MODE` in the shared settings file `~/Development/.env` (or `STANDALONE_ENV`), read with `util.parseEnv`, one key only. The server port variable is now `PORT` (was `GATEWAY_INSPECTOR_PORT`). `/api/*` answers say `mode: "mock"` (was `demo`).
- Presenter mode (P, Esc) that keeps the mode and the banner. The header Reset also resets the diagram boxes. `npm run reset` and `npm run smoke`.
- UI: the vendored shared stylesheet, byte-for-byte from the parent, plus an app stylesheet that uses tokens only; dark and light come from the shared file.
- Removed: the SE k8s build (manifests, deploy script, `docs/k8s.md`, `MODE=se-mock`, the HOSTED SIMULATION banner, per-visitor workspaces and the `X-Workspace-Id` header, `VITE_BASE_PATH`), the repo-root `.env` loader, and the self-hosted CI. Docker is the only packaged form.
- Shelf entry: the `composeFile` is relative. The copy of the shelf's registry rules accepts relative paths.
